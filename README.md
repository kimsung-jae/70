# 보글사다리 TARGET 70 V1.2

## 목적
현재 후보 중 가장 높은 %를 억지로 최종픽으로 쓰지 않고, **실제로 70%를 넘긴 규칙을 합성하고 독립구간에서 다시 확인**하는 실험판입니다.

## TARGET 70 엔진
- 기초 신호: Markov, 변화 N-gram, Shape, k-NN 유사문맥, Run-Length, Lag, Regime, 최근빈도
- 서로 다른 계열 3개를 한 규칙으로 합성
- 정방향/역방향 규칙을 각각 독립 후보로 검사
- 약 5만 개 합성규칙을 매 분석 시 검증
- 가중치 학습 없음: 합성된 3개 모델은 각각 1표

## 70% 승인 절차
1. 과거 회차를 한 회씩 가리는 walk-forward 예측을 생성
2. 앞 calibration 구간에서 70% 이상인 안정 규칙을 1개 선택
3. 그 규칙을 고정
4. 뒤 holdout 구간에서는 규칙을 바꾸지 않고 독립검증
5. **holdout 70% 이상 + 전체 70% 이상일 때만 최종 1픽 승인**
6. 미달이면 가장 높은 후보를 대신 사용하지 않고 `70% 목표 조합 생성 중`으로 유지

## 데이터
- API에서 새 결과를 받을 때 기존 기록과 idx로 병합
- 학습용 결과는 최근 최대 150회 누적
- 초기 설치 직후에는 API의 최근 데이터부터 시작하며, 시간이 지나면서 누적 표본이 증가
- 기존 JSON 백업 가져오기 지원

## 현재 30회 백업으로 한 안전검사
기존 231~260회 30개 백업을 넣어 엔진을 실행하면 calibration에서 70% 이상 규칙은 만들어졌지만, 별도 holdout에서 70%가 재현되지 않아 최종픽 승격을 거부했습니다. 이것은 의도한 동작입니다. 같은 구간에서 찾은 높은 숫자를 그대로 70%라고 부르지 않기 위한 보호장치입니다.

## 설치
GitHub 새 저장소에 원클릭 `.sh` 파일 하나를 올린 뒤 Codespaces Terminal에서 실행합니다.

```bash
bash 보글사다리_TARGET70_V1.2_원클릭.sh
```

Actions > Build Android APK > Artifacts > `BubbleTarget70V12-debug-apk`

패키지: `com.bubbleladder.target70v12`
기존 MHS 앱과 별도 설치됩니다.

> 표시되는 70%는 과거 독립 holdout 재현값이며 미래 당첨을 보장하지 않습니다.
